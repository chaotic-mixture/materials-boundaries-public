# 样本数口径澄清：未知确切n不等于n数值为空

本次不改变任何原生材料／性质／来源对象，也不改变作者的样本数。修正的是历史清单中文表头与统计口径说明。

旧R2机器字段 sample_count_value_missing 实际统计value为空。该数值是正确的，但中文“确切n为空／缺失”容易被理解成全部确切n未知。4条PHBV性质只报告至少5重复，value=5、relation=at_least，确切n也未知；不能当作恰好5。

当前r18的139条聚合物实验性质记录中：59条报告确切n，76条n数值未报告，4条仅报告至少5；确切n未确认共80条。4条PHBV性质不是4个已知独立试验组，重复计数的性质说明不能转换成试样、独立批次或材料数量。

历史口径：r15为63条数值为空＋4条下限＝67条确切n未确认；r16为70＋4＝74；r17和r18均为76＋4＝80。历史数字来自各自冻结R2清单的逐条sample_count，未重跑历史原生回归。旧冻结审阅输入／回执／阶段README保持不变；3份未冻结本地进度入口已作措辞澄清，并保存更正前副本。

[当前R3清单](native-r18/README.zh.md)及INVENTORY_R3.json保留与R2相同的139条完整记录和所有既有条件统计，并增加总体／来源的关系分类、确切n已报告和未确认数量。温度未报告仍95、调湿未报告仍104；不存在默认n、条件补值或完整率评分。
