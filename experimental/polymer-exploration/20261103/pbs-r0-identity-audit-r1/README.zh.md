# PBS R0：身份映射暂缓判定

此项是对已有 PBS 草案中 R0 暂缓原因的补查，不是新材料接纳或新的原生候选。已有9条强度草案及组合 r2 的冻结内容均不变。

来源为 Ewurum / McDonald（2025），[DOI 10.3390/polym17020194](https://doi.org/10.3390/polym17020194)。本轮使用已保留的原文 XML：140387字节，SHA-256 `a16999d84b85e49d09979b2d32804e9e9763bc0478449d9a4a2c3c346d7a4a1a`；未新增 PDF 页图核对。方法、制备与选中数值来自 §§2.1–2.4、2.9、Tables 1、6。CC BY 4.0 的文章原始事实限量策展，原文资产仍在仓库外。

Table 6 的 R0 强度为 `35.9 ± 2.1 MPa`，Young 模量为 `801 ± 121 MPa`，脚注定义均值 ± SD，并保留 SD 舍入说明。§2.9 的拉伸重复数为10，独立生产批次数未知。原文方法可以定位，但尚无可直接复用的 R0 原生状态。

阻止直接映射的具体证据：

1. 现有 `mat_ewurum2025_biopbs` 的名称与 `identity_scope` 明确限定为 B0 未填充 PBS 对照，不能默认为涵盖反应系列。
2. §2.3 区分 B 系列与含 DCP 的 R 系列，并给出0.25 wt.% DCP添加说明。最终反应程度、残留和网络拓扑不能从加入量推出；不把添加比例自动转换为最终固化组成。
3. 已有 R10/R20/R30/R45 有各自来源配方身份；历史接纳说明明确未选择 R0。不能仅凭相近标签复用任一个复合配方身份，也不能把历史未选择误写成作者没有报告。
4. Table 1 的 R0 凝胶分数单元格是“—”，不是0。§2.4凝胶分析对应热压材料；不能将其自动移给注塑拉伸状态，也不能仅凭原文“crosslinked”称谓赋予定量交联密度。

依据 [贡献规则](../../../../docs/DATABASE_CONTRIBUTING.zh.md)，不同状态使用新记录；但此规则本身没有证明 R0 与严格限定的 B0 共用同一身份。依据 [身份计数规则](../../../../docs/MATERIAL_GROWTH_1000_PER_CLASS.zh.md)，状态、标签、重复观察均不能增加身份数。

**结论：R0 继续暂缓原生映射。** 不挂到 B0，不新增身份或状态，不把两个性质填入其他状态。后续身份审阅须明确比较两条路径：有证据支持且明确修订范围的同一基础聚合物/新状态，或有独立身份理由的来源反应配方；任何路径都保留牌号歧义、未知最终化学及未知测试温湿度/调湿。数值差异或“交联”称谓本身不裁决身份。

`DECISION_R1.json` 绑定原文、现有身份对象及历史说明；本轮属于策展调查，不是独立身份审阅或科学验证。原生库、旧候选、组合预览和远端均未改变。
