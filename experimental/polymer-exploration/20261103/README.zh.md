## 执行顺序

1. 冻结现有聚合物来源与状态清单，先比较条件和性质缺口。
2. 优先形成一份可直接追溯原文、带逐文件许可和分组映射的实验来源审计。
3. 对已有身份优先增加来源限定状态/性质；相同化学名称不自动合并牌号或模型。
4. 候选与已审核阶段分开，未知温度、湿度、n、误差定义不补默认值。
5. 完成实际数据/契约检查及适用审阅后积累交付；本轮不立即推送。
