## 选择与未知边界

- 全部54组来源统计中，1项强度已存在、8项进入本次草案、45项暂缓；这些不是54个新材料或已接纳数量。
- Table 6的路线标签存在歧义，本批全部暂缓，不把C和C+S统一。
- Table 7参考态模量和老化后强度的常规CV舍入区间不相容，继续保留原值并暂缓。选择同组另一性质不为整组作科学认证。
- HP材料身份／牌号对应未完成，未并入EOS身份；断裂伸长没有新增量契约。
- 375／750小时是来源报告的加速腔体时间，“6／12个月”是作者换算标签，不能当作本项目验证的自然寿命。
- 38°C空气、55°C黑标、50%RH照射阶段的暴露条件与实际拉伸测试温湿度分开。实际测试温湿度、调湿／干燥、暴露后恢复时间和精确模量提取窗口仍未知。
- 115mm仅为原文测试段长，不称为已确认引伸计标距；不同位置的后处理顺序差异照录，不补操作时长或精确执行顺序。
