# NBR REF 既有密度记录复核

本轮为来源复核与使用边界补充，不新增材料、不修改原生记录。

来源：[Tamás-Bényei / Sántha，2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12750214/)，DOI `10.1021/acsomega.5c05493`。本轮实际阅读 PMC HTML 的 §§2.1–2.3、Table 3 与 §3.4；未重新取得有效 PDF/XML，也未重新进行 PDF 页图检查。旧记录的 PDF 哈希不是本轮下载结果。

§3.4 明确将 REF 的 `1.031 ± 0.001 g/cm³` 归于硫化配方的密度测量。REF 不含再生碳纤维，但仍包含助剂，不能作为纯 NBR 或未硫化原料的密度。§2.1 的原料标称密度、D 与 D_Fo 的结果及发泡条件均不能替换 REF 记录。

在上述检查范围内，密度专属的方法、标准、体积约定、测试温湿度、调湿/储存、重复数、汇总方式及 ± 统计定义仍无法确认。硬度测点、磨耗样本数、机械试验标准及其统计分析不能移用于密度。网页对 Supporting、humidity、Data Availability 的查找未命中，仅为导航辅助，不证明所有补充资料均不存在。

继续保留 `reported_value`、`reported_plus_minus_unspecified` 及未知条件。该记录仅支持来源限定的目录参考，不能直接用作工程许用值、纯胶通用常数或精确质量/浮力设计依据。未进行独立科学验证。

`SOURCE_READBACK_R1.json` 记录本轮证据层级；运行 `verify_readback.py` 可核对绑定的原生文件与记录。它不联网，也不代替原文审阅或完整历史回归。本地积累后再统一推送。
