# NR 来源计算热导率：隔离溯源原型，尚未接纳

当前正式实现仍为已独审的r40：5415性质、5263状态。原文明确λ=αcpρ，NR热导率0.132±0.003W/m·K继续暂缓。本目录探索来源计算值的通用溯源规则，不改变当前生产代码、原生目录或已安装包。

原型使用新的闭合标签 thermal_transport_product_unpaired_context_v1，方法 source_reported_thermal_transport_product，类别 published_measurement_derived_reference/source_reports_calculation。公式须有同一主文档的方法证据；热扩散率、质量比热、质量密度三种输入角色只能保存“来源上下文”与原文定位，不提供可冒充实际配对输入的数值槽位。

实际输入值、试样配对、密度温度一致性、计算与汇总顺序、协方差、原文误差传播方法均为null并附未知范围说明。软件计算和软件误差传播标志必须为false。不以表格汇总值重算、认证四舍五入等价或恢复误差。本原型范围限于未验证实际输入的来源计算情形；将来若获得配对原始输入，须另审扩展，不能把已核实值塞进本原型的未知槽位。

check_prototype.py仅运行虚构对象的隔离schema和语义检查；一个有效对象通过、17类错误声明被拒绝，结果见PROTOTYPE_CHECKS_R1.json。此处不是完整图、生产实现、原生映射、实际安装或科学认证。生产模块和三张原生表的前后哈希保持一致。

后续接线必须保留旧木材经验换算分支及其数值审计，新增分支不能扩大旧profile枚举。新方法、profile、性质类别、来源计算标签须双向约束。四语展示必须使用专用来源计算说明，不能显示旧木材的物种/标本/含水率说明。完整查询、导出恢复、副本隔离、原生状态链接、实际安装与独审仍是后续关口。
