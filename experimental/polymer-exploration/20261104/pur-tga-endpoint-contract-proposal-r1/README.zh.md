# PUR 热重端点契约提案 R1

本包仅设计数据契约，尚未实现、原生接纳或推送。28 条来源事实已经来源独审；这不构成本提案、实现或接纳的批准。

范围为四个既有 PUR 配方各七个表格单元：首次热重起始温度、5% 和 10% 失重温度、三个来源标记的 DTG 峰温，以及 700 °C 残留百分数。计划共用四个独立 TGA 状态，不增加材料身份，不将 28 个性质拆成 28 个状态。

四类性质分别建模。失重水平、峰序号、残留端点温度是有类型且有证据的坐标，参与语义去重；不能只放在名称中。失重和残留都必须说明质量参考基准，本来源不能确认的基准保留未知。保留来源百分数原尺度，不自动换算为 0–1，也不从接近 100% 的曲线起点推断干基或初始质量基准。残留允许零值，拒绝负值；不将其自动认定为组分质量分数、灰分或工程许可值。

来源的 ± 含义和单元格确切样本数未确认，不能提升为均值、标准差或 n=3。TGA 通用方法段的“三个或更多平行样品”单独保存，不能填成每格样本数。温度差幅度不应用摄氏/开尔文零点平移。SPO-2 的 5% 失重温度低于起始温度仍按原文保留，不能以排序规则修正。两条 DSC 冲突线索继续暂缓，与本提案分开。

实现须保留现有七个 schema 分支和旧值域，追加四个完整分支；检查字段所属分支、证据、未知基准、单位角色、重复判定及四语言展示。质量失重百分数仅是坐标单位角色，不能混入性质中心值的单位集合。新温度性质须获得温度值域与不确定度差值语义检查，而不能扩大旧 Tg/熔融分支的量枚举。

`SOURCE_ROLE_CROSSWALK_R1.json` 是不完整的契约示例，不是合法原生记录。`VALIDATION_R1.json` 只记录提案结构、数量与当前不支持新量的检查；实现测试、安装和接纳均未运行。冻结入口为 `REVIEW_INPUTS_R1.json`，后续审阅回执单列，不能将来源批准替代契约批准。
