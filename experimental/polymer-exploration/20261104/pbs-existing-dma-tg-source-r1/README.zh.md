# 既有 PBS 配方 DMA Tg 来源与方法提案

已核对原文PDF第3、4、8、9页以及XML Table3，冻结9个既有配方的DMA Tg候选。数值和Unicode负号保持源写法；R0仍排除。候选不是新身份，分类保持1个聚合物、8个聚合物基复合配方。

方法为DMA-7三点弯曲、15mm跨距、3×5×20mm试样、1Hz、0.2%应变、−50至120°C／3°C/min，Pyris v13.3；Tg判据明确是tanδ最大值。实际DMA条形试样的后续成形路线、循环、气氛、预载和调湿未知，不从DSC、TGA或注塑拉伸补齐。0.2%的峰值／RMS等振幅约定未说明，不能补造。

原文确认DMA共同方法三次重复；提案保留此事实，选定单值的确切贡献次数、汇总及不确定度暂不确定，交由独审裁定。Table3没有将Tg标成均值或附SD。§3.5笼统提到DSC Tg，但所选值在§3.4／Table3明确由DMA tanδ峰给出，这项源内差异保留。

现有glass_transition_temperature运行时没有限定仪器，但说明文档只写DSC。因此提出方法限定说明扩展，不新增量、单位或分支；提案和冻结前文见相应文件。未修改主契约说明，未映射、安装或应用DMA记录，未推送、合并main或部署。
