# 玻璃化转变温度的方法适用范围提案

将现有说明中仅以DSC举例的标题和段落扩展为“来源报告、方法限定的玻璃化转变温度”，允许使用既有glass_transition_temperature坐标分支记录作者明确命名的DMA Tg。物理量、单位、五个互斥分支、旧对象和运行时均不改；不是把DMA复制成DSC，也不把不同方法同名数值视作可互换常数。

每条DMA候选需保留作者判据（本批为tanδ最大值）、频率、应变振幅及其未说明的幅度约定、温度扫描速率、夹具／跨距／试样几何、软件和循环信息或未知。另建DMA状态，不能复用DSC状态或注塑拉伸状态。扫描速率与动态加载频率分别记录；不把Hz当成静态拉伸速率，不把共同重复声明改写成确定的单格均值或SD。

查询同一quantity可以返回不同方法的完整来源对象。源标签、方法、判据、条件和未知项必须随每个对象保留，不能按量名或数值去重、求均值、推换算关系或自动认定可比。DSC的起始／中点／拐点、DMA的储能模量下降起始／损耗模量峰／tanδ峰均按原文区分；本文只选择明确给出的tanδ峰，不补其他判据。

Tg仍为目录用途，不作通用界限、工程许用值、可用温度或引擎输入；不声称符合原文未引用的DMA标准。现有有符号温度及不确定度差值规则保持。拟用虚构的同身份、同温度、不同方法／状态样本核验完整查询、导出及四语言展示，验证软件保存区别，不把软件测试当作物理可比性证据。
