# Şahin 既有聚合物：五条交流介电击穿性质原生映射草案 r1

本包是未应用的草案，承接来源独审与单独的契约实现候选。NEW_STATES_R1.json 含五个电气圆片状态，NEW_PROPERTIES_R1.json 含五条电场性质；只关联已有 PLA、ABS、PETG、ASA、PC/ABS 身份，不新增身份、牌号或来源。

五个中心值逐字使用已独审 §3.2 文本，不从图估读。ASA 为明确的均值，另四条统计量未知；每组样本数为 3 次电气测量，数值不确定度为空。测试/油温、频率、RMS/峰值、成品调湿、实际厚度及电场方向与打印层关系等未知项均明确保留。干燥属于丝材加工；50 mm × 1.2 mm 为名义圆片尺寸。不得套用现有拉伸状态的温度、n=5、SD、试样几何或统计定义。

在隔离契约下，加入草案后的内存全图 5,376 条性质、5,250 个目录状态校验通过。原有 5,371 条性质、5,245 个状态、全部身份与牌号对象完全相同；唯一来源变动候选为已独审的一条 PDF URL 和一条说明追加。此结果不表示原生接纳、安装完成或远端 CI 通过。

首次映射校验因缺少 test_method 和 direction 两项必填条件失败，补齐有来源的方法与明确未知方向后通过。开发前版本及诊断记录保留在仓库外；未修改校验规则。未运行 HTTP、完整历史回归或安装检查。本包须经只读独立映射审阅后，方可进入原生接纳准备。
