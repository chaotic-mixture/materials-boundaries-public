# PLA/PCL：官方 PDF 与剩余条件追查

已取得 Delgado-Aguilar 等（2020，DOI 10.3390/ma13112655）的官方 18 页 PDF，核对第 1、3、4、5、6、10、11、14、18 页。七个既有配比的 25 条拉伸性质逐格与 Table 2 一致：7 条模量、7 条强度、4 条断裂伸长率、7 条最大应力处伸长率。Table 3 实验栏佐证强度；不选择理论列。原始 PDF、页图、文字提取及官方附件仅在仓库外保存。

PDF 第 11 页的标准差说明仅支持既有模量的 SD，不扩展至强度和伸长率。25 条性质的中心汇总、n、测试温度、RH、成形后调湿、具体拉伸几何和方向仍未确认。第 4 页的 60°C 原料干燥、颗粒存放及 210°C MFI 条件不能用来填测试温度或调湿；115mm 是夹头间距，2mm/min 是横梁速率，5kN 是载荷传感器容量。标准引用不补默认试样尺寸或条件，不认证合规。成形温压的段落差异继续保留。

官方 Europe PMC 补充文件包内的 6 页 PDF 已逐页查看：Tables S1–S7 是 PP、HDPE、ABS、PS、PA12、PA6 商业产品与 MatWeb 引用列表，没有为所选 PLA/PCL 测试提供新增调湿或 n 依据。不导入其中商业性质，也不把论文 CC BY 4.0 视为其链接网站、厂商资料或标准的统一许可。补充文件实际保留 FOR PEER REVIEW／Published:date 占位，不能据此编造最终修订信息。

官方主 PDF 含嵌入图形的旧排版文字，自动提取可能出现重复段落及旧页码；按可见正文页码和表格判断，不把这些重复计作另一批实验。仅声称选定事实相符，不声称整份 PDF 与 XML 完全等价。最新修订、更正、撤稿状态仍未知。主文第 18 页的文章 CC BY 4.0 声明已查看。
