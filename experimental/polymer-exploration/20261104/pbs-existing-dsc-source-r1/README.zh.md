# 既有 PBS 配方：DSC 熔融温度来源候选

本批从 Ewurum／McDonald（2025，DOI 10.3390/polym17020194）的 Table 4 提取9个既有配方的 Tm 字面值：B0、B10、B20、B30、B45及R10、R20、R30、R45。已取得官方原文 PDF 并查看第3、4、9、10页，逐行核对既有 XML。原始附件、文字提取和页图均留在仓库外。

候选只补现有身份的热性质；计划建立挤出材料的独立 DSC 状态，不能复用注塑拉伸状态。R0仍因身份未解决而排除。BioPBS FZ91PM/FZ91PB牌号歧义、最终反应组成与网络程度未知保持。

方法来自§2.8的DSC段：DSC-7、名义样品10mg、30–150°C升温、冷却回30°C、再次升温，升降温速率为±10°C/min。第二次升温依据是§3.5／图4的共同上下文，并非每个表格单元格单独标注。列标签保留原表 Tm；正文把大主峰称为Tm2，不增造约102°C的小峰数值。

正文主峰范围有113–115°C及113.2–115.6°C两种写法，表中整数包括B10=116°C和B30=113°C。候选按表保留整数精度和范围差异，不反推小数或将差异当不确定度。原文未明确的DSC重复数、统计、气氛、软件、校准、盘及调湿保持未知；DMA的三次重复和TGA的氮气不能移入。
