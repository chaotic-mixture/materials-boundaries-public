# 体积百分数水吸收：实现阶段

新增第19个闭合性质分支water_absorption_volume_percentage，物理维度dimensionless，专门中央单位percent_water_absorption_volume，来源显示V%／vol.%／vol%。仅收实验来源、常规测量、报告汇总、标量及非负固定小数；0可表达，不暗设100上限或饱和含义。数域只验证记录结构，不自动确认异常源值；实际接纳仍须独立来源核验，未知体积基准不能作为异常值准入理由。

water_absorption_definition强制保留体积基准、浸水暴露、液体、试样几何、预处理、水温和表面水处理。reported须明确文本；unknown／not_verified须null和说明；每项有同所检主文档条件证据，报告项另须方法证据。不能缺省、not_applicable或推测补值。

旧18分支和旧定义保持；新分支独享绝对不确定度及多重幅度定义，V%不是相对误差百分数。支持未知±含义、SD／CI等既有证据规则，绝对幅度必须同水吸收单位；无质量/体积换算、外推或ISO认证。定义补充或小数尾零不制造同源格新事实。四语展示全部定义和使用边界。
