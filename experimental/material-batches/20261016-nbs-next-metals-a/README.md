# NBS 1953 palladium, silver and tin facts

This packet contributes three composition-level metal identities, each with
one source-qualified state and one NBS crystallographic-density fact. It reuses
the existing `swanson_tatge_1953_nbs_circ539v1` source record without changes.

| Identity | Selected source state | Density (grams per cubic centimeter) | Density temperature | Printed / PDF page |

| Tin | Johnson, Matthey & Co., London white/beta sample | 7.286 | 26 degrees C | 26 / 30 |

PDF page numbers are one-based. The sample and thermal preparation for tin
are on printed page 24 / PDF page 28. Introduction page 2 / PDF page 6 supplies
the original density-unit wording. Local images were actually read and compared
with extracted text; page locators use the printed labels rather than the
initial page-start hints. The complete retained PDF has SHA-256
`003b872fbe7d403d38bbd1d752568ee92a96bdb010b6e381bdc82566929e2a6c`.

The values are source calculations from measured X-ray lattice parameters,
classified as `published_measurement_derived_reference` with crystallographic
density basis. They are not direct specimen bulk-density measurements or
powder/sponge packing densities. No lattice or density value is recomputed.

Palladium's impurity ranges and vacuum heating remain state context; the heat
treatment is not the 25 degrees C density temperature. Silver's source purity
is greater than 99.999 percent, with an unspecified percentage basis. It is not
the bismuth-rich comparison sample discussed elsewhere in the source. Tin's
reported 99.997 percent is explicitly by difference, not an independent direct
purity measurement; its 160 degrees C anneal does not replace its 26 degrees C
density reference temperature. Tin is one identity, and beta is a state qualifier.

Density uncertainty, pressure, independent physical-specimen count, supplier
lot/grade and percentage bases remain unknown. All four authored locale slots
use English fallback labels. Scientific-review and raw-reanalysis flags remain
false; all results are catalog-only, non-universal and non-allowable.
