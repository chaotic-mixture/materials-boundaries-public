# JARVIS：每类 1000 目标的金属与无机来源储备

本包只做固定来源审计和后续契约准备，**接纳增量为零**，不修改当前铝合金回归的输入。
候选身份、类别与来源条件仍须独立审核。

## 实际取得和核算的文件

固定 [Figshare v11](https://doi.org/10.6084/m9.figshare.6815699.v11) 的文件
`64391379`：`jdft_3d-9-24-2025.json.zip`，48,447,610 字节。
与官方 MD5 `c3179161ef0d029cf1fa70da463aac6e` 一致；SHA-256 为
`f9e0a3309f0000d5de1ec9e49c93963109ea45e63f451103f8f6595d2eabf7f5`。
完整源文件与组成索引保存在仓库外；本包保存脚本、来源证据及小型核验收据。

解压成员实际含 **93,902 行**，不是旧版加载器的“76k”宣传数量。
筛选要求源明确写明 OptB88vdW、三维体相、正有限数密度、有效元素与坐标数量、
源 `nat` 一致、源公式与原子计数的精确组成比一致。保留 **45,909 行**。

| 筛选桶 | 合格源行 | 精确约分后的组成组 |
| --- | ---: | ---: |
| 仅金属元素 | 18,467 | 14,028 |
| 含 O 且不含 C/H | 8,472 | 5,320 |
| 其他，类别待解 | 18,970 | 14,482 |

共有 33,830 个组成组。相同组成的不同 JID/物相不重复计入本表；同一组的最小数字
JID 仅作为索引代表，不代表最稳定相、唯一材料或已接纳身份。上表不能加入项目配额。

排除 46,214 行未明确满足选定三维体相条件、1,778 行 `nat` 不符合本筛选器的
精确整数/原子数条件，以及 1 行非正密度。合格行与排除行之和恰为全部源行。
字段不符的行被保留为排除记录，不推断其在其他用途无效。

源文件有 179 行含非 JSON 标准的 `NaN`，本次共定位到 1,280 个未选弹性张量单元。
首次严格 JSON 读取因此失败，未报告为通过。后续采用带类型的来源缺失 token 保留异常，
不把它改成零或运行数值；选定密度与几何出现此类 token 仍拒绝。

## 下一步的真实门禁

目前运行契约把 `crystallographic` 密度与实测输入推导绑定，无法诚实地表达本源的
DFT 优化晶胞密度。不能用改标实验、隐藏已知基础或随意填写普通体密度绕过。
先审阅[计算晶胞密度契约提案](COMPUTED_DENSITY_CONTRACT.zh.md)，再形成冻结名单、
与现有材料及正式计算组成做有限交叉映射，并复核分类、方法和使用条件。

本源足以支持进一步筛选，不证明已经有 1000 个可接纳的新金属或无机身份。
聚合物和复合材料的缺口仍需各自来源，不能由本源替代。
