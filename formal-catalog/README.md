24 reviewed computed composition buckets under formal-project-count-policy/1,
for 1081 formal project admissions.

This unmerged local experiment contains 1083 source-qualified identities and the
same 24 computed buckets, totaling 1107. Main remains unchanged. Resource pins
match the local core for reproducible testing; they do not publish a release.

Install after the pinned core with `pip install ./formal-catalog`, then run
`materials-project-catalog`. See `../docs/FORMAL_PROJECT_CATALOG.md` for policy,
provenance, interfaces and limitations. No deployment or mutable admission is enabled.
