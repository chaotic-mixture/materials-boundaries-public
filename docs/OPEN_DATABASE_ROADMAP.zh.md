# 开放材料数据库整改

目标：让使用者能够查找、下载、引用和贡献来源可追溯的材料性质记录；数据更新与计算引擎发布解耦，局部变更不默认触发完整历史回放。

## 实施与验收范围

- [x] 数据访问：稳定记录 ID、条件与未知值、来源和许可元数据完整保留，支持筛选及可复现快照下载。
- [x] 数据契约：公开字段字典、机器可检验格式与贡献样例；区分转录核对、独立科学审核和正式发布。
- [ ] 增量更新：按记录识别新增、修改和删除，检查受影响关联与科学约束；报告绑定前后快照。
- [x] 贡献流程：候选、审核和发布阶段明确，不用历史全套回放替代数据审核。
- [x] 验证与发布：快速数据门禁、针对性测试、发布验收分层；数据版本与引擎版本分离。
- [x] 用户入口：README 以真实查询场景开篇，展示数据、下载和贡献路径，保留科学边界。
- [ ] 交付：验证安装包内的数据库入口和示例，整理可审阅 Git 差异及交付状态。

## 首个可用入口

在源码目录或安装包环境中：

```sh
python -m materials_boundaries.database query --query C11000 --quantity mass_density
python -m materials_boundaries.database export --query C11000 --quantity mass_density --output copper-snapshot
python -m materials_boundaries.database check
```

JSONL 导出保留完整性质、材料状态、身份、牌号及关联来源。manifest 给出数据库内容指纹、过滤条件、记录数和文件校验和。导出不是审核批准，不推断工程许用值，也不将来源许可替换为项目代码许可。

本路线图是整体整改的工作清单；新增查询入口不代表整体目标已完成。
