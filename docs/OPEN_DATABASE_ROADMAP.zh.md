## 首个可用入口

在源码目录或安装包环境中：

```sh
python -m materials_boundaries.database query --query C11000 --quantity mass_density
python -m materials_boundaries.database export --query C11000 --quantity mass_density --output copper-snapshot
python -m materials_boundaries.database check
```

JSONL 导出保留完整性质、材料状态、身份、牌号及关联来源。manifest 给出数据库内容指纹、过滤条件、记录数和文件校验和。导出不是审核批准，不推断工程许用值，也不将来源许可替换为项目代码许可。

本路线图是整体整改的工作清单；新增查询入口不代表整体目标已完成。
