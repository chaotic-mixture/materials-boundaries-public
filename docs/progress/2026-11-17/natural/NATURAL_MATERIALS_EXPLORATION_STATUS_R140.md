## Twining-bean stem modulus data screened

Added `phaseolus-hel-da-stem-modulus-2026-data-screen-r1/PHASEOLUS_HELDA_STEM_MODULUS_2026_DATA_SCREEN_R1.md` for the climbing-plant stem mechanics deposit. Version lineage was reconciled: Zenodo 18865114 is the v0.9 preprint release and 21805961 the v1.0 post-review record for the same article; Zenodo 15545548 is a separate earlier dual-axial-force-method dataset.

The public repository has 60 section CSVs and 235 `avg` rows. Seven experiment/section keys repeat; matching the analysis dictionary’s last-row overwrite yields 226 experiment/section profiles. The first four 5-cm stem bins each have 45–57 profiles, with code-compatible median fitted Young’s modulus rising from 4.417 to 113.046 MPa. These remain exploratory fitted stem-section estimates, not raw-curve re-fits. Several repeats have decimal-scale radius/modulus differences, the dataset license is not established, and the `Helda` label is not elevated to species-level identification.

Sources: [Zenodo v0.9](https://zenodo.org/records/18865114); [Zenodo v1.0](https://zenodo.org/records/21805961); [analysis repository](https://github.com/merozlab/ohad-2026-cn-mech-twine).
