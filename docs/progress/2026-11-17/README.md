## 研究资料

- [天然材料](natural/)　R140 核对攀援豆茎秆数据版本，整理 226 个实验与茎段组合的拟合剖面。
- [金属](metal/)　筛查 Ti-6Al-4V 增材制造资料及 6061-T651 批次与温度记录。
- [聚合物](polymer/)　PHBV-39 SEC 来源补核 R3 保留测试方法与温度的未知状态。
- [无机材料](inorganic/)　审阅氮化硅晶须拉伸及氮化铝八个烧结状态的热导率与弯曲强度。
- [复合材料](composite/)　推进玉米湿磨副产物与再生 PP 的来源内对照、配方筛查及实验设计。部分规划底稿标注 11 月 18 日，按计划材料收录。
