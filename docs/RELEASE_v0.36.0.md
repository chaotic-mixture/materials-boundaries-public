# v0.36.0 — public database and executable mechanics

本次将开发分支中已提交的数据库成果交付到公开 main 和 GitHub Release。
相对此前 main 的 1057 个材料身份、1057 条性质，发布快照包含 5180 个身份、
5262 个来源限定状态和 5412 条性质。不同证据类别保持分开；不把计算记录当成实验材料。

新增用户能力：

- 数据库查询、概览、下载、快照校验、差异比较和增量验证。
- 两个可执行力学模型：弹性常数换算与三维各向同性应力—应变/刚度/能量。
- 随包知识条目提供公式、来源、适用条件与限制，可用 knowledge 命令查询。
- 首页以安装、真实数据查询和计算示例为中心；开发验收日志移至历史入口。
- wheel、源码归档与原生数据库下载附件，软件版本与数据指纹分别记录。

发布检查包括当前数据库契约、数据库专项、新力学模型测试、原有引擎/输入验证测试、
版本元数据与真实安装入口。历史全量回放仍可手动运行；其旧精确字节基线
不是 v0.36.0 已通过的证据。本次不声称全套历史回放或所有实验平台都通过。

原有 8 条复合材料规则和 41 条历史知识记录保留，不为凑数量改写。
新模型不产生屈服/断裂预测，也不授予数据库材料工程许用值。来源许可保持原状态。
